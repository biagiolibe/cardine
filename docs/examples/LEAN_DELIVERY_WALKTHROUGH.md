# A first task with the lean preset

Follow [First 5 minutes](../../README.md#first-5-minutes) for the current
end-to-end Contoso example: declare validation, adopt the project, configure
the host, create a task, and ask the agent to follow `cardine run 001` until
it finishes or stops. The example uses the `lean` preset; the same lifecycle
also supports `governed` defaults and per-task overrides.

The former walkthrough described an earlier lifecycle and is no longer an
executable Cardine example.
