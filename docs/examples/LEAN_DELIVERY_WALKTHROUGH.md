# A first task with the lean preset

Follow the [Quickstart terminal section](../QUICKSTART.md#start-in-the-terminal) for the current
end-to-end path: run `cardine init`, register a task, and run
`cardine run 001` until it finishes or stops. The example uses the `lean` preset; the same lifecycle
also supports `governed` defaults and per-task overrides.

The former walkthrough described an earlier lifecycle and is no longer an
executable Cardine example.
