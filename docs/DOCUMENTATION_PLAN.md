## Audience and positioning

The README serves prospective adopters: it must explain the product, the installation path and where to start. The quick start serves a developer initializing a project and delivering a first task; the agent reference serves the agent following a task through its actual lifecycle and recovery. The authority is the ADR, not a new product promise: “Cardine is the delivery discipline for AI coding agents” and “Every task lands on `main` validated, integrated, and reversible, or it stops with a reason and the exact command to resume” (ADR L98–100). It calls Cardine a new product originating in Meridian (L84–94), and says “one lifecycle, one engine, and one template set” with Lean and Governed presets (L123–148). Its README line is “Specs say what to build. Orchestrators run the agents. Cardine makes sure what lands on main is right” (L118–121).

The reference must distinguish the published surface: “Human-readable output is never stable. Tooling must use `--format json`” (`docs/PUBLIC_SURFACE.md:34–38`). Managed workflow and README adopter commands are stable; host entry points are host-facing, the console experimental, and repository maintenance helpers internal (L19–33). The same source currently says the compatibility promise starts at 1.3.0 (L13), whereas the 1.0 ADR restarts it at 1.0.0 (ADR L93–94): D5 must resolve this against release authority rather than silently invent a promise.

Repository task records, release fragments, `commands/` and test fixtures are outside the requested directories; the slash commands are nevertheless a stable surface (`docs/PUBLIC_SURFACE.md:129–130`). Counts are case-sensitive whole-word occurrences, including code and historical text; the parenthesized lines identify every occurrence (multiple occurrences on one line count separately). Command column lists inline code and fenced lines beginning with a shell command; line numbers point to the original, and `none` means no such quotation. Syntax fragments are preserved as written, not assertions that they can be executed unchanged. Readers describe the principal audience. “Keep” means preserve and verify, not freeze. Maintainer archive means retain history separately from adopter navigation; proposed destination is `docs/archive/`, subject to DD2.
