# Task Execution Queue

This is the operational execution queue. Tasks are ordered by priority.

Fully closed phases or sections (all `[x]`) belong in `QUEUE_ARCHIVE.md`, not here.
This file tracks only work with open items, keeping the reading cost low in every
session.

Authority for this queue: [docs/ADR_CARDINE_1_0.md](../docs/ADR_CARDINE_1_0.md),
"Work items to 0.9".

## How to use this queue

- **Execution**: The developer assigns a specific `[ ]` task; agents do not
  select work autonomously.
- **Update**: Task branches do not edit this file. A row keeps `[ ]` until
  `meridian worktree integrate stage` sets `[x]` on the merged candidate;
  in-progress state is derived from the task branch, its registered worktree,
  and the unarchived task record.
- **Delegation**: Follow the delegation block at the end of each task file.
- **Task-file archive**: The task branch moves its completed task file to
  `tasks/done/`.
- **Queue archive**: `integrate stage` moves the rows of a fully closed phase
  to `tasks/QUEUE_ARCHIVE.md` instead of accumulating them here.
