## Objective

Task 286 lets the directive name the reviewer host, for example
`Proceed with 290 reviewer codex`. Without a name, the agent's own host reviews. In
`cardine console`, the `l` key opens the launch panel, where the developer picks the
agent, Claude Code or Codex, and the console starts it with the task directive
(`_launch_request` in `src/cardine/console/launch.py`, near line 64). The panel offers no
reviewer choice, so a launch from the console always gets the default.

### 1. The reviewer choice

After the agent is chosen, the launch panel (`_draw_launch_prompt` in
`src/cardine/console/render.py`, near line 586, and its keys in
`src/cardine/console/entry.py`, near line 272) shows one more line:

    Reviewer: same as agent (claude)    Tab: switch to codex

- The default is the same host as the agent.
- `Tab` switches between the two hosts. It must not clash with the keys the panel already uses.
- The panel states the choice before the launch is confirmed.

The choice is shown only when the selected task's frozen `reviewSources` contain
`launched`. Otherwise the panel is unchanged.

### 2. The directive

When the chosen reviewer differs from the agent, the launched directive is
`<directive> reviewer <host>`, for example `Proceed with 290 reviewer codex`. When it
is the same, the directive stays as it is, because the agent's own host is the default.
`_launch_selected`, near line 145, still checks that the task's directive did not change
before it launches.

The `[copy]` action keeps copying the plain directive.
