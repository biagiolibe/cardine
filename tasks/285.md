## Objective

On 2026-11-12, `cardine console` showed task 245 as `Closing`, a day after it landed.
macOS Finder had written a `.DS_Store` file into the empty placeholder directory that
cleanup leaves at the old worktree path.

After `git worktree remove`, `finish_delivery` recreates an empty directory at the
worker path and records its identity: `cleanup_placeholder`, near line 331 of
`src/cardine/integration/cleanup.py`. `_completed_observation`, near line 93, requires
that directory to exist, to keep its identity, and to be empty. So any file that the
operating system, an IDE or a backup tool writes there makes a landed task look
unfinished. The console then lists it as `Closing` with `CLEANUP_BLOCKED`. The
placeholders also pile up: one empty directory for every landed task under the worktree
root.

Cleanup completion must rest on facts that Cardine owns: Git and receipts.

### 1. No placeholder for new cleanups

`finish_delivery` no longer creates a placeholder or records `placeholder`. A new
intent does not require `cleanup_placeholder`. After `cleanup_worktree`, if the worker
path still exists as a directory holding only operating-system metadata, remove it.
Use the helper of part 3 for that test.

### 2. Completion from Git and receipts

`_completed_observation` holds when all of these hold:
- every required effect is `done`;
- `main` contains `binding['main']`;
- the task branch is gone;
- no Git worktree is registered at the worker path;
- the lifecycle file is gone.

The worker path may be absent, or a directory that holds only operating-system
metadata. Its identity and contents are no longer evidence.

For intents written before this change, which require `cleanup_placeholder` and carry
`placeholder`, apply the same rule. The recorded effect must still be `done`, but the
placeholder identity is ignored, in both the historical and the replay observation.

### 3. Path reuse checks

In `_local`, near lines 170 to 174, and `_new_intent`, near line 222, an unregistered
directory at the worker path is a reuse only when it holds something other than
operating-system metadata. Real files still stop with `reused worktree path preserved`,
so user data is never removed.

Add one helper, `_only_os_metadata(path)`. It returns true for a directory, not a
symlink, whose entries are all among `.DS_Store`, `._*` files, `.localized`,
`Thumbs.db`, `desktop.ini`, `.Spotlight-V100` and `.fseventsd`.

### 4. Find the reason first

Before changing anything, read `git log -S "cleanup_placeholder" -- src/cardine/integration/cleanup.py`
and any ADR or document that explains the placeholder. If it protects against a race
that part 3 does not cover, stop with `BLOCKED` and name it.
