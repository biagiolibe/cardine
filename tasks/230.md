## Objective

Row D6 of `docs/DOCUMENTATION_PLAN.md`. Documents drift: the rewrite of 225, 226 and 227 fixes
them once, and nothing keeps them right.

Extend `check_template_commands` / `unknown_template_commands` in
`scripts/check_repository.py`, which already walks the CLI parser tree, to scan the fenced
command examples of the adopter documents and managed skills. An example that names an unknown
`cardine` command path fails with its file and line.
