## Objective

After task 290, `cardine setup --check` (`print_setup_plan` in
`src/cardine/hosts/setup.py`, near line 466) printed this on a consumer project on
2026-11-12:

- **Summary** lists each change twice: once grouped by target, on one line, and again as
  a `- <change>` bullet with the full path.
- **Next steps** prints `next: cardine setup --apply`, then a numbered list that repeats
  it. With nothing to change, the list starts at "2." and still asks to restart the
  agent.
- **Planned file changes** holds every status fact of the setup: worktree root,
  directory, hooks, allowlist, plugin, skill links and `CARDINE_ROOT`. The diffs sit
  among them.
- The warnings come last as plain `warning:` lines. One actionable fact is hidden inside
  `claude-detail`: the project allowlist keeps entries that Cardine did not write, such
  as `Bash(git push origin main)`. That entry lets the agent push `main` without asking.

### 1. Summary

Print `changes on --apply: <n>`. Then, for each target with changes (Claude Code, Codex,
this project, Cardine home), print the target as a sub-heading and one bullet per change.
Paths are relative to the project, or start with `~/`. Each change appears once.

### 2. Next steps

A numbered list only:
- with changes: `cardine setup --apply`, restart the agent, `cardine doctor`;
- without changes: "Nothing to change", then `cardine doctor`.

Drop the `next:` line, and number from 1 in both cases.

### 3. Status

A new section "Status" holds the status facts that today sit under "Planned file
changes", as `key: value` lines, with their current keys and values.

### 4. Planned file changes

Only the diffs, each under a line naming its file. When there is no diff, the section is
left out.

### 5. Warnings

A last section "Warnings", only when there is one. It holds:
- the existing `warning:` lines, as `warn` lines;
- one warning per kept allowlist entry that Cardine did not write:
  "project allowlist keeps <entry>, which Cardine did not write; remove it from
  .claude/settings.local.json if unwanted".

Move that fact out of `claude-detail`, which keeps the rest of its text.
