## Objective

With one agent already beside the console, launching a second one with `l` fails. Task 210
collects the other panes of the tab with:

```applescript
set end of agentSessions to contents of aSession
```

In iTerm2's scripting dictionary, `contents` is a property of a session: the text on its
screen. The list therefore holds strings, and `tell (item -1 of agentSessions)` cannot
split a string. The coordinator confirmed this on 2026-11-09 with a read-only script: the
selected item had class `text` and held the output of the agent's pane.

In `_apple_script` (`src/cardine/console/launch.py`), replace the list with a variable, as
the function already does for the console session. The lines from
`set agentSessions to {}` to the final `end if` become:

```python
        "set lastAgent to missing value",
        "repeat with aSession in sessions of targetTab",
        f'    if unique id of aSession is not "{session_uuid}" then set lastAgent to aSession',
        "end repeat",
        "if lastAgent is missing value then",
        "    tell targetSession to set newSession to (split vertically with default profile)",
        "else",
        "    tell lastAgent to set newSession to (split horizontally with default profile)",
        "end if",
```

The same read-only script confirmed that `lastAgent`, set this way, is a session with the
expected unique id.
