## Objective

The console launches an agent with `l` by splitting its own iTerm2 pane horizontally
(`_apple_script` in `src/cardine/console/launch.py`). Every launch takes height from the
console: with two agents running, the console, which needs height for its task list,
shows about nine rows and its details end in "more below", and each agent pane is just
as short. The developer reported on 2026-11-08 that every pane reads badly.

After this task, the panes form two columns:

- the first agent launched from a console that is alone in its tab splits the console
  vertically, so the agent opens on the right and the console keeps its full height;
- each later agent splits the last other pane of the console's tab horizontally, so the
  agents stack in the right column and the console never shrinks again.

The developer can drag the divider once to give the console the width it needs (110
columns for the details pane); later launches do not change the console's size.

## Technical Context

- The coordinator compiled this fragment with `osacompile` against the iTerm2 dictionary
  on 2026-11-08 (compiled only, never run). It follows the existing session loop, which
  also records `targetTab` when it finds the console session; `<uuid>` is the console
  session's unique id, interpolated as today:

```applescript
set agentSessions to {}
repeat with aSession in sessions of targetTab
    if unique id of aSession is not "<uuid>" then set end of agentSessions to contents of aSession
end repeat
if (count of agentSessions) is 0 then
    tell targetSession to set newSession to (split vertically with default profile)
else
    tell (item -1 of agentSessions) to set newSession to (split horizontally with default profile)
end if
```

- iTerm2 gives a split half of the split pane. A narrower console switches to its narrow
  layout, which keeps the list and opens details with Enter; that is expected.
- The project's standing decisions are in `PROJECT_WORKFLOW.md`, section `Standing
  decisions`.
